---
title: "Scrape a page"
description: "POST /v1/teracrawl/scrape fetches a URL through a Driver browser and returns the page as HTML or Markdown."
---

One call, one page, no session to manage. Driver opens the URL in a real browser, waits for it to settle, gets past anti-bot challenges where it can, and returns the content.

<CodeGroup>
```bash cURL
curl -X POST https://api.driver.dev/v1/teracrawl/scrape \
  -H "Authorization: Bearer $DRIVER_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://example.com","output":"md"}'
```
```typescript TypeScript
const { data } = await fetch("https://api.driver.dev/v1/teracrawl/scrape", {
  method: "POST",
  headers: { Authorization: `Bearer ${process.env.DRIVER_API_KEY}`, "Content-Type": "application/json" },
  body: JSON.stringify({ url: "https://example.com", output: "md" }),
}).then((r) => r.json());
console.log(data.content);
```
```python Python
data = requests.post(
    "https://api.driver.dev/v1/teracrawl/scrape",
    headers={"Authorization": f"Bearer {os.environ['DRIVER_API_KEY']}"},
    json={"url": "https://example.com", "output": "md"},
).json()["data"]
print(data["content"])
```
</CodeGroup>

## Response

```json
{
  "success": true,
  "data": {
    "content": "# Example Domain\n\nThis domain is for use in illustrative examples…",
    "format": "md",
    "finalUrl": "https://example.com/",
    "statusCode": 200,
    "navigations": 1,
    "totalTimeMs": 2140
  }
}
```

## Options

| Field | Type | Default | What it does |
|---|---|---|---|
| `url` | string | required | The page to fetch. |
| `output` | `html` \| `md` | `html` | Return raw HTML or Markdown. |
| `smartdoor.waitForSelector` | string | | Wait until this CSS selector exists before extracting. |
| `smartdoor.waitForSelectorValue` | string | | Text the selector's element must contain. |
| `smartdoor.waitForFunction` | string | | A JavaScript expression that must be truthy before extracting, e.g. `window.dataLoaded === true`. |
| `smartdoor.timeout` | integer | | Overall timeout in ms, 1000 to 60000. |
| `smartdoor.delay` | integer | `0` | Extra wait in ms after the page settles, up to 30000. |
| `smartdoor.challengeBudget` | integer | `4100` | How long to wait for an anti-bot challenge to clear, in ms, 2000 to 30000. |
| `smartdoor.nodes` | array | | Preferred placements, e.g. `[{"type":"hosted","country":"US"}]`. Any match is acceptable. |

```json
{
  "url": "https://example.com/products",
  "output": "md",
  "smartdoor": {
    "waitForSelector": ".product-grid",
    "challengeBudget": 10000,
    "nodes": [{ "type": "hosted", "country": "US" }]
  }
}
```

## Errors

`401` for a bad key; `500` with `{ "success": false, "error": "…" }` when the page could not be fetched within the budget.

## When to use a session instead

Use a [browser session](/docs/sessions/create) when you need to sign in, click through a flow, keep state between pages, or watch what happens. Scrape is for "give me this page".
