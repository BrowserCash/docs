<CodeGroup>
```bash cURL
curl -X POST https://api.driver.dev/v1/teracrawl/search \
  -H "Authorization: Bearer $DRIVER_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"query":"Neon serverless postgres funding","maxResults":5}'
```
```typescript TypeScript
const { data } = await fetch("https://api.driver.dev/v1/teracrawl/search", {
  method: "POST",
  headers: { Authorization: `Bearer ${process.env.DRIVER_API_KEY}`, "Content-Type": "application/json" },
  body: JSON.stringify({ query: "Neon serverless postgres funding", maxResults: 5 }),
}).then((r) => r.json());
for (const r of data.results) console.log(r.score, r.title, r.url);
```
```python Python
data = requests.post(
    "https://api.driver.dev/v1/teracrawl/search",
    headers={"Authorization": f"Bearer {os.environ['DRIVER_API_KEY']}"},
    json={"query": "Neon serverless postgres funding", "maxResults": 5},
).json()["data"]
for r in data["results"]:
    print(r["score"], r["title"], r["url"])
```

## Options

| Field | Type | Default | What it does |
|---|---|---|---|
| `query` | string | required | The search query. |
| `maxResults` | integer | `5` | 1 to 20. |
| `includeContent` | boolean | `false` | Also return each result's full page as Markdown in `content`. Slower; use it when the snippet is not enough. |

Results are reranked, and `score` (0 to 1) is the reranker's relevance. `knowledgeGraph` is present when the query resolves to an entity.

## For agents

Search plus scrape covers most "look something up" tasks without a browser session: search for candidates, scrape the one or two pages that matter. Reach for a session only when the answer is behind a login or an interaction.
